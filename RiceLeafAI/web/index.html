What to photograph

From photo to prediction

The scanner resizes a photo to 64 × 64 pixels and divides it into 16 tiles. Each tile contributes colour and edge measurements, giving the classifier 224 features. It compares the image with four rice classes.

How do we evaluate the solution?

Training images teach the models. Validation macro F1 helps select a model while giving each class equal weight. A held-out test set measures accuracy, macro precision, and recall. The confusion matrix shows which diseases the selected model confuses.
